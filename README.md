# CCD — Licenciatura en Ciberdefensa

Repositorio de estudio, preparación y laboratorio para la **Licenciatura en
Ciberdefensa** de UNDEF (FADENA), con inicio de cursada en el **primer
cuatrimestre de 2027**.

Acá vive el **contenido** de la carrera: programa, fichas de materias,
material de estudio, prácticas y el entorno técnico donde se ejercitan.
La **agenda** (qué se hace cada semana, seguimiento de consistencia, revisiones
semanales) sigue viviendo en Coach/trajectory. El puente entre ambos está
diseñado en [`docs/integracion-coach.md`](docs/integracion-coach.md).


## Punto de partida en una línea

37 materias, 2624 horas cátedra, 4 años, título intermedio a los 3
(*Analista Universitario en Gestión de Riesgos Cibernéticos*). La carga real de
cursada ronda las 20 h semanales de clase; con estudio, entre 35 y 45 h/semana
en cuatrimestre. Ese número manda sobre cualquier plan que se escriba acá.
